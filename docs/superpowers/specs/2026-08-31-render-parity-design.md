# Blender / Web 渲染一致性规格

## 目标

让网页端加载 `models/ship-blender.glb` 后的默认画面，与 Blender 生成的 `models/ship-blender-preview.png` 使用同一套展示参数：相机位置与目标、灯光方向与颜色、深色世界背景、色调映射和海面高度/材质保持一致。模型仍然由 Three.js 负责交互，预览场景不会写入 GLB。

## Blender 参考参数

| 项目 | Blender 参考值 | Web 适配规则 |
|---|---|---|
| 相机 | location `(205, -190, 105)`，look-at `(0, 0, 6)`，48 mm，36 mm sensor | 按 `export_yup=True` 转为 GLTF 坐标，再按 GLB 居中/归一化比例变换 |
| 坐标 | Blender：X 船长、Y 左舷、Z 垂向 | GLTF/Web：X 船长、Y 垂向、Z 由导出坐标变换得到 |
| 世界 | 背景 `#05080f`，弱世界光，深色氛围 | 外部 Blender 模型使用同一背景和较低环境强度 |
| 主光 | `(45, -100, 145)`，暖白 | Web 用定向光近似，并使用同一坐标变换 |
| 补光 | `(-95, 85, 92)`，冷蓝 | Web 用定向光近似，并使用同一坐标变换 |
| 轮廓光 | `(20, 30, 125)`，冷蓝 | Web 用定向光近似，并使用同一坐标变换 |
| 前补光 | `(0, -150, 55)`，浅蓝 | Web 用定向光近似，并使用同一坐标变换 |
| 海面 | Blender Z `-9.55`，尺寸 `340 × 340`，颜色 `(0.015, 0.09, 0.14)` | 创建为外部模型展示层的水平 Y-up 平面，随模型归一化比例变换 |
| 输出 | Eevee，1600×900，AgX Medium High Contrast | 使用 Three.js AgX（不可用时回退 ACES）和同等曝光基线 |

## 行为约束

1. 默认外部 GLB 使用 Blender 展示参数；`?demo` 的程序化示范船保留现有网页灯光、海面和相机行为。
2. 外部模型加载时，隐藏程序化模型的海面，避免两个不同高度的海面叠加；清理外部模型时恢复程序化海面。
3. 外部模型加载和替换不得破坏结构树、BOM、选择、爆炸、剖切、推进演示、管路动画和撤销状态。
4. `Fit` 仍然是用户主动触发的自动适配命令；默认载入后的第一帧使用 Blender 展示相机。
5. GLB 继续排除 Blender 预览相机、灯光和 `Preview Ocean`，以免把展示辅助物混入工程模型。

## 验收标准

- 自动化契约测试能确认参考相机、坐标转换、展示灯光、海面和生命周期钩子均存在。
- Blender GLB 工件校验仍通过，并确认 `Preview Ocean` 不在 GLB 节点中。
- 浏览器加载默认 GLB 后，模型视角与预览图同为右舷高位斜视构图，海面位于船底以下，结构树与属性仍可操作。
- GitHub Pages 入口能加载更新后的静态资源。
